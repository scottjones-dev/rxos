# Accessibility review

- [ ] Contrast, type size, line spacing, truncation, and icon meaning are reviewed.
- [ ] Focus order is logical, complete, visible, and recoverable.
- [ ] Touch targets and spacing meet the scaled minimum.
- [ ] Reduced motion removes nonessential animation.
- [ ] Expanded, accented, non-ASCII, mixed numeric, and RTL content works.
- [ ] Warnings use text and icon in addition to colour.
- [ ] Keyboard and rotary emulation can reach all cabin functions.
- [ ] Screen-reader and colour-vision strategy is recorded as future work.
