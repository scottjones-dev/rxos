# Cabin touch session

Status: **open — representative touchscreen required**.

Run the guided session for dock items, Back, Home, settings controls, sliders,
toggles, warning acknowledgement presentation, scrolling, minimum targets, and
edge/corner targets.

- Automated result: attach machine-readable hit, coordinate, bounds, miss
  distance, duration, adjacent activation, and edge/corner classification.
- Human observation: note reach, glare, delay, accidental activation, and focus.
- Physical measurement: active area, bezel, scale, mounting angle, and reach.
- Reviewer decision: accept, resize/reposition, or reject.
- Open issue: list missed or ambiguous targets without identifying the tester.
- Retest requirement: required after layout, scale, display, mounting, or input
  driver changes.

Collect no biometric data. Warning acknowledgement is presentation-only and
never means a vehicle condition is resolved.
