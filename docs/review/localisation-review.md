# Localisation review

- [ ] Translation keys are complete and stable machine identifiers remain untranslated.
- [ ] Development translations are labelled unreviewed.
- [ ] Expansion delimiters expose every truncation point.
- [ ] RTL mirroring, bidi punctuation, numbers, units, focus order, and icons are reviewed.
- [ ] Long warning, navigation, media, and settings text reflows, elides, or scrolls.
- [ ] Speed, RPM, gear, warning, and freshness hierarchy remains dominant.
- [ ] Date, time, decimal separator, units, missing, stale, and simulated formats are correct.
- [ ] Professional translation review is required before production use.
