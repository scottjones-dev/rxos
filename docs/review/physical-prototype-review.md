# Physical prototype review

No item below has been validated. Complete this checklist only on
representative, safely mounted hardware in a stationary mock-up or controlled
review environment.

- [ ] Steering-wheel occlusion and driver eye position
- [ ] Viewing angle, daylight readability, night glare, reflections, and brightness
- [ ] Reach distance, touch accuracy, and glove use
- [ ] Vibration and operating temperature
- [ ] Cold/warm boot time and shutdown behaviour
- [ ] Power-loss and recovery behaviour
- [ ] Audio and visual distraction
- [ ] Display mounting and retention
- [ ] Airbag deployment zones
- [ ] Demisting airflow
- [ ] Hazard-button access
- [ ] Factory warning and instrument visibility

This checklist is not automotive certification or safety validation.
