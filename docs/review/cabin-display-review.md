# Cabin display review

- [ ] Every application is reachable by touch, keyboard, and rotary-style focus.
- [ ] Focus is visible and Escape/Back/Home behaviour is consistent.
- [ ] Touch targets remain at least the scaled 56-by-56 minimum.
- [ ] Persistent header and dock do not hide or trap page content.
- [ ] Overflowing content scrolls; dialogs remain within screen bounds.
- [ ] Placeholders do not imply routing, media providers, diagnostics authority, or control.
- [ ] Warning and freshness states remain visible on every page.
- [ ] Day/night, scale, units, expanded text, and RTL layouts are reviewed.

Desktop review is not physical touch-reach validation.
