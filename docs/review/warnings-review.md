# Warning presentation review

- [ ] Every warning includes stable ID, text, icon, severity presentation, source, and timestamp.
- [ ] Colour is never the only distinction.
- [ ] Simulated conditions are explicitly labelled simulated.
- [ ] No threshold or response is represented as verified Mazda behaviour.
- [ ] Acknowledgement never implies the underlying condition cleared.
- [ ] Multiple warnings preserve the most severe visible state.
- [ ] Stale and disconnected telemetry cannot appear live.
- [ ] Factory instrumentation remains authoritative.
