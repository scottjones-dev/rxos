# Milestone One UI

The driver display prioritises speed, RPM, gear and data quality. Daily mode
uses a navigation instruction placeholder; Track mode gives more space to
telemetry and a lap-timer placeholder.

The cabin display provides navigation, media, vehicle overview, telemetry,
diagnostics and settings navigation. All content is simulated or placeholder
content.

Both displays show connection state at all times. The driver display obscures
instrument values when the stream is not live. The cabin display retains its
last sample with a prominent non-authoritative banner.
