# Prototype bill-of-materials guidance

This is a category guide, not a purchasing recommendation. Consumer components
must not be described as automotive-rated.

| Category                     | Minimum                                                       | Preferred                                                                   | Confirm                                                            | Main risks                                              | Temporary alternative                            | Production difference                                            |
| ---------------------------- | ------------------------------------------------------------- | --------------------------------------------------------------------------- | ------------------------------------------------------------------ | ------------------------------------------------------- | ------------------------------------------------ | ---------------------------------------------------------------- |
| Prototype computer           | Linux, two independent display outputs, Qt 6-capable graphics | Documented GPU driver, enough RAM for both release displays, stable cooling | GPU/API, two simultaneous native modes, boot and thermal behaviour | Shared output bandwidth, driver instability, throttling | Development laptop/dock after assignment testing | Automotive temperature, EMC, power, lifecycle and serviceability |
| Driver display               | One supported landscape geometry, digital input               | Wide landscape panel with measured brightness and viewing angle             | Active area, density, refresh, glare, latency                      | Wheel occlusion, scaling, adapter EDID loss             | Desktop monitor cropped to target geometry       | Custom optics, mounting, retention, environmental rating         |
| Cabin touchscreen            | 1920×1080 or higher landscape display and USB touch           | 2560-class panel with reliable multitouch and low edge error                | Active area, USB mapping, target accuracy, brightness              | Touch mapped to wrong output, bezel reach, glare        | Desktop touch monitor                            | Automotive touch controller, coatings, gloves, retention         |
| Display cables/adapters      | Correct signal and bandwidth for both modes                   | Locking, short, well-shielded cables                                        | EDID preservation, refresh, hot-plug recovery                      | Intermittent signal, role identifier changes            | Certified desktop cables                         | Locking automotive connectors and EMC evidence                   |

## Before purchasing

Record candidate specifications without asserting compatibility. Confirm two
simultaneous outputs, native refresh, Linux driver support, Qt rendering API,
EDID stability, physical dimensions, brightness controls and touch mapping.

## Before physical review

Enter measured—not advertised—active area, bezel, mounting offsets, eye point
and steering-wheel geometry. Photograph or diagram the setup and identify every
value that remains assumed.
