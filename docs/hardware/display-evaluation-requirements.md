# Representative display evaluation requirements

This document defines evidence to collect before selecting either 15-inch
display. It does not recommend a panel.

Record the exact panel, controller, cable, firmware, compositor, Qt backend and
mounting geometry. Test native resolution and expected scaling for:

- daylight, night and high-contrast legibility;
- black level, glare, reflections, viewing angle and dimming range;
- pixel density, colour stability and motion clarity;
- cold start, resume, signal loss and display reconnect;
- frame pacing at 1, 10, 20, 30 and 60 Hz telemetry;
- cabin touch accuracy, minimum target size, gloves and edge reach;
- driver non-touch operation and steering-wheel occlusion;
- thermal soak and brightness derating;
- electromagnetic, vibration and automotive environmental suitability when
  the project reaches the relevant review stage.

The factory cluster remains installed and authoritative. A representative test
must include stale, malformed, disconnect and reconnect scenarios and confirm
that missing RXOS data cannot obscure the factory instruments.
